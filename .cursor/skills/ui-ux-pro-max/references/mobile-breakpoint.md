# Mobile Breakpoint Conversion

Review selected frames and convert them so that they are in a mobile breakpoint size (390px wide), responsively resized to that screensize.

## Important guidelines

- Stack multi-column and horizontal layouts into single-column vertical layouts
- Scale typography and spacing proportionally for mobile readability
- **Preserve all image fills exactly as they are — do not change image scale modes, cropping, or aspect ratios. Keep images at their original scale mode (typically FILL) and adjust the container dimensions to maintain the correct aspect ratio at mobile width instead.**
- Keep all content, imagery, and visual style intact — only restructure for the smaller screen
